## Установка

### Windows
1. Установи Git: https://git-scm.com/download/win
2. Скачай проект:
   - Открой командную строку
   - Выполни:
   ```bash
   git clone https://github.com/ТВОЙ-USERNAME/monster-tier.git
   cd monster-tier


## Обновление проекта

Когда я добавляю новые вкусы или меняю описания, обнови проект одним из способов ниже. **Все твои оценки и перетаскивания сохранятся** — они хранятся в браузере.

### Windows
Дважды кликни по `tools/update.bat` — скрипт сам скачает обновления и откроет сайт.

### macOS
Дважды кликни по `tools/update.command`.
> Если macOS ругается на «неизвестного разработчика»: правый клик по файлу → «Открыть» → подтвердить.

### Linux
Открой терминал в папке проекта и выполни:
./tools/update.sh
Если не запускается — сделай исполняемым один раз: `chmod +x tools/update.sh`

### ⌨️ Вручную (любая ОС)
Открой терминал в папке `monster-tier/` и выполни:
